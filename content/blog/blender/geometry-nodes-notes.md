# 几何节点笔记：让重复变得有生命

做《极光之城》之前，我搭城市的方式是：建一栋楼，复制，旋转，再复制……一百栋楼之后，手和心都累了。

几何节点改变了这件事。这篇文章是我的实践笔记，不按官方手册讲，只讲我在项目里真正用到的套路。

## 套路一：实例化 + 随机

核心就一句话：**先造一个「细胞」，再让节点把它撒满全场**。

```text
Grid → Distribute Points → Instance on Points → 楼体几何
```

给每个实例一个随机种子，高度、切角、屋顶天线都从这里取值：

```text
Instance on Points
├── Selection: 随机阈值（控制稀疏）
├── Scale: Random Value（高度变化）
└── Rotation: Random Value（轻微旋转，打破阵列感）
```

## 套路二：用曲线做「路径感」

城市不能只有楼，还要有「流」。车流、人流、光带——本质都是一条曲线加实例化：

```text
Curve Line → Resample Curve → Instance on Points → 车体
```

配合 `Sample Curve` 的因子，可以让车在路径上变速，拥堵感一下就出来了。

## 套路三：噪点纹理做「生长的边缘」

植被边缘、云朵边缘、苔藓覆盖……都靠噪点纹理当蒙版：

```text
噪点纹理 → Color Ramp → 阈值 → 作为 Selection
```

Color Ramp 的两端拉近，边缘就锐利；拉开，边缘就柔和。调这一个节点就能控制「生命感」的程度。

::warning
几何节点不是万能的。几千个实例以内的场景用它很爽，上百万实例时先想清楚是否需要 GPU 实例化。
::

## 我的工作流

1. 先做**一个**完美的手工样板
2. 再用节点把它实例化、随机化
3. 最后用噪点纹理加「不完美」

手工样板定上限，随机定下限，噪点负责把中间填满。

> 一句话总结：节点的价值不是省事，是让重复看起来像是有意为之。
