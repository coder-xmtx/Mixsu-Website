# 为什么我的渲染看起来很假：黄金时刻的光线

「看起来假」是每个渲染新手都会收到的反馈。模型明明很细，材质明明很贵，问题到底出在哪？

我排查过一轮，结论是：**90% 的假感来自光线**。

## 检查清单

### 1. 光的方向：永远不要顶光直射

顶光 = 证件照。真实世界的太阳很少在头顶正上方。

试试黄金时刻：太阳高度角 **10°~20°**，影子被拉长，物体有了体积感。

### 2. 色温：不要一白到底

真实光线是有色温的：日出偏橙红，正午偏白，阴影偏蓝。

一个立刻见效的做法：**主光 5500K，补光 7500K**。冷暖对比一出来，画面立刻「活了」。

### 3. 衰减：光是要「落下来」的

点光源默认按物理衰减（平方反比），很多新手把它改成「无衰减」——这是假感的一大来源。**保持物理衰减，把强度调大**，光才会在物体上留下真实的明暗过渡。

## 一个黄金时刻的灯光配置

以下是我常用的「黄金时刻」三灯法：

| 角色 | 类型 | 色温 | 强度 | 高度 |
| ---- | ---- | ---- | ---- | ---- |
| 太阳 | Sun | 4500K | 3.0 | 15° |
| 天光 | Sky（HDR） | 7500K | 1.0 | — |
| 补光 | Area | 6500K | 0.5 | 地面高度 |

再加一层体积雾（密度 0.005~0.01），让阳光有「穿过空气」的质感。

::note
体积雾不要加在整张图上。用一个 Box 只包住场景主体，否则远景会糊成一片。
::

## 最后的检查

渲染完成后，把画面转成灰度看一眼：**如果明暗关系依然成立，光就是对的**。颜色是装饰，明暗才是骨架。
